## 🚀 Projets phares

### ⚡ ENERCA 2.0 — Site web officiel de l'Énergie Centrafricaine (2026)

> Plateforme institutionnelle complète pour l'entreprise nationale d'électricité de la République Centrafricaine.

- 🏗️ **22 pages publiques** : présentation, timeline historique interactive, carte Leaflet, tableau de bord énergétique, médiathèque, documentation PDF…
- 🔐 **Back-office complet** : 24 modules CRUD, système de rôles 3 niveaux (super_admin / admin / rédacteur), journal d'actions
- 🗄️ **30+ tables MySQL** : infrastructures, actualités, clients, factures, tickets de panne, données de production…
- 🔒 **Sécurité complète** : CSRF, PDO préparé, bcrypt, rate-limiting, sessions sécurisées, headers HTTP, validation upload MIME
- 📊 **Dataviz** : Chart.js (barres + courbes), mix énergétique 105,77 MW animé
- 🗺️ **Carte interactive** : Leaflet + OpenStreetMap, marqueurs typés, modal détail, galerie photos

**Stack :** `PHP 8` · `MySQL 8` · `Apache` · `JavaScript ES6` · `Leaflet` · `Chart.js` · `CSS3`
